# ⚡ Multi Tool Hub

**Multi Tool Hub** là extension Chrome tập hợp các tiện ích hữu ích: Đánh giá DTU nhanh, Tải tài liệu Studocu không watermark, Tải PDF Scribd, Chụp ảnh Web, Làm sạch Text và nhiều tính năng khác.

---

## 📦 Tính năng

### 🎓 Đánh giá DTU
- Tự động điền form đánh giá giảng viên (câu 1-53)
- Hỗ trợ các mức xếp loại: Tốt → Kém
- Tự động điền nội dung đánh giá theo xếp loại

### 📚 Studocu Tools
- ✅ Tải file PDF không watermark
- ✅ Xem file & xóa watermark
- ✅ Lưu trang thành ảnh (.PNG)
- ✅ Tự động load toàn bộ trang trước khi tải

### 📄 Scribd Tools
- ✅ Tải file PDF
- ✅ Xem file & xóa watermark
- ✅ Lưu trang thành ảnh (.PNG)
- ✅ Tự động load toàn bộ trang trước khi tải

### 📸 Chụp ảnh Web
- ✅ 3 chế độ: Toàn trang, Khung nhìn, Chọn phần tử
- ✅ Định dạng PNG / JPEG
- ✅ Tải xuống hoặc sao chép vào clipboard
- ✅ Chỉ chụp nội dung web, không lấy UI trình duyệt

### 🧹 Làm sạch Text
- ✅ Xóa HTML tags
- ✅ Xóa Markdown formatting
- ✅ Xóa Unicode control characters
- ✅ Xóa định dạng bảng
- ✅ 3 cấp độ lọc: Cơ bản → Tiêu chuẩn → Nâng cao
- ✅ Tự động phát hiện định dạng ẩn
- ✅ Xóa bullet, số thứ tự, quote, dấu phân cách
